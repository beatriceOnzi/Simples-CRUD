# CRUD de Usuários

Projeto simples de CRUD desenvolvido com Node.js, Express, MongoDB e Handlebars.

## Funcionalidades

- Cadastrar usuários
- Listar usuários
- Editar usuários
- Excluir usuários

## Tecnologias

- Node.js
- Express
- MongoDB (Mongoose)
- Handlebars
- Tailwind CSS

```
Estrutura
├── app.js
├── models/
├── views/
├── public/
└── package.json
```

## Como executar

1. Instale as dependências:

```bash
npm install
```
Configure a conexão com o MongoDB no arquivo app.js.
Inicie o projeto:
```
node app.js
```
Acesse no navegador:
```
http://localhost:8081
```
